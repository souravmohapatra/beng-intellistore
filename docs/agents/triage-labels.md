# Triage labels

Use these canonical roles unchanged as local `Status:` values.

| Role | Local value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires evaluation |
| needs-info | needs-info | Waiting for clarification |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Implementation completion uses `done`; claims use `Claimed by:`.
Wayfinding decisions use `open`, `claimed`, and `resolved`.
These are lifecycle conventions, not additional triage roles.

These values are local metadata; no GitHub labels need to be created.
